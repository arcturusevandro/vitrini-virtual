# Vitrini Virtual — Portfólio de Conteúdo Digital

Projeto web desenvolvido para apresentar serviços e trabalhos relacionados à **produção de conteúdo digital, edição de vídeos e uso de Inteligência Artificial na criação de apresentadores digitais**.

A aplicação funciona como uma vitrine profissional simples e responsiva, reunindo proposta de valor, serviços, portfólio e canais de contato em uma única página.

## Objetivo

Criar uma presença digital direta para demonstrar serviços e projetos audiovisuais, com foco em uma experiência visual simples, rápida e adequada para desktop e dispositivos móveis.

## Funcionalidades e estrutura

- apresentação dos serviços em landing page;
- seção de portfólio;
- incorporação de conteúdos em vídeo;
- chamadas para ação e contato;
- layout responsivo;
- identidade visual própria;
- navegação em página única.

## Tecnologias

- HTML5;
- CSS3;
- design responsivo;
- incorporação de mídia e links externos;
- Git e GitHub para versionamento.

## Contexto

O projeto também registra uma etapa de experimentação com soluções digitais voltadas à comunicação, marketing e aplicação de IA na produção de conteúdo.

Ele complementa meu portfólio técnico ao demonstrar construção de uma interface web orientada a uma necessidade concreta de negócio e comunicação.

## Status

Projeto funcional mantido como parte do portfólio.

# Development Instructions

This repository follows the Evandro Development Standard, aligned with current OpenAI Skills/Plugins engineering guidance.

## Scope
This is a lightweight portfolio website. Prefer simplicity, accessibility, performance and maintainability over unnecessary frameworks or dependencies.

## Frontend workflow
1. Inspect the existing HTML/CSS structure before editing.
2. Make the smallest useful change and preserve working content.
3. Validate responsive behavior on mobile and desktop.
4. Check navigation, media embeds, links, calls to action and basic accessibility.
5. Avoid unnecessary JavaScript and third-party dependencies.
6. Optimize media and avoid changes that materially degrade page load.
7. Document meaningful behavior or structural changes.
8. Keep Git history truthful and incremental.

## Security and privacy
Never commit credentials, tokens, private contact data or other secrets. Review external embeds/links before adding them.

## QA
For visual changes, inspect the rendered page rather than treating source-code validity as sufficient validation.
